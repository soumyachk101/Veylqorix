[h1] Verify the code your agents wrote.
[span] Before it ships.
[p] Veylqorix independently verifies AI-generated and human-written code before it is committed, pushed, merged, or deployed. It orchestrates real scanners — dependency auditing, secret detection, license checks, static analysis, and test suites — normalizes their output into one finding schema, and turns it into a deterministic gate decision with auditable evidence.

[span] Why Veylqorix
[h2] Four guarantees
[p] AI coding agents now write a large share of production code — fast, plausible, and occasionally unsafe. Lint and CI pipelines were not designed to verify that volume. Veylqorix fills the gap:
[p] Guarantee 01
[h3] Real evidence, no fabrication
[p] Every finding, severity, and exit code comes from an actual scanner run. A check that cannot run is reported SKIPPED or ERROR with a reason — never a clean pass.
[p] Guarantee 02
[h3] One engine, many surfaces
[p] CLI, MCP, GitHub Actions, and the dashboard are thin adapters over a single core, so security logic exists in exactly one place and behaves identically everywhere.
[p] Guarantee 03
[h3] Deterministic gate
[p] Exit codes are stable — 0 PASS, 1 FAIL, 2 INCOMPLETE — so CI branching is predictable and auditable run to run.
[p] Guarantee 04
[h3] Agent-safe policy
[p] An AI agent cannot suppress findings or raise thresholds: exceptions must be documented, capped, expirable, and visible in the committed policy file and every gate report.
[span] One engine, many surfaces
[h2] Where Veylqorix plugs in
[p] Every surface is a thin adapter over the same core engine (
[code] packages/core
[p] ), so there is exactly one place where security logic lives:
[h3] CLI
[p] Real scans, deterministic exit codes, safe dry-run hook installer. Not published to npm yet — run from dist/.
[h3] MCP server
[p] Six validated tools, root-confinement + redaction. Requires pnpm build.
[h3] GitHub Actions gate
[p] Real scan + SARIF upload, all actions pinned to SHAs. Advisory until a branch-protection rule requires the check.
[h3] Agent skills
[p] Portable SKILL.md plus MCP configs for Claude Code, Codex, and Cursor.
[h3] Dashboard
[p] Live scan data from the API; clearly-labeled DEMO MODE when the API is down.
[p] Honest note
[p] The gate and the CLI hooks are
[strong] advisory
[p] until enforcement is in place — a branch-protection rule that requires the check, or a published CLI. Findings are produced and the check fails; a merge can still be forced. That is stated everywhere, never hidden.

[span] Honest limitations
[h2] What Veylqorix is not
[p] Read this first
[li] Veylqorix reports what its scanners found. It does not certify the
[em] absence
[li] of vulnerabilities or secrets.
[li] A scanner that cannot run makes the gate INCOMPLETE (exit 2) — degraded coverage is surfaced, never green-washed.
[li] Regex secret detection has false positives and negatives; it complements tools like Gitleaks, it does not replace them.
[li] License scanning is manifest-level, not a transitive license audit. A clean quality check is not a security certification.
[blockquote] A check that cannot run is reported SKIPPED or ERROR with a reason. Veylqorix surfaces incomplete audits instead of green-washing them.
