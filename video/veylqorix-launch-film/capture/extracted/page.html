No Unsafe Code Gets Throughshowcase

Verify the code your agents wrote. Before it ships.

Veylqorix independently verifies AI-generated and human-written code before it is committed, pushed, merged, or deployed. It orchestrates real scanners — dependency auditing, secret detection, license checks, static analysis, and test suites — normalizes their output into one finding schema, and turns it into a deterministic gate decision with auditable evidence.

Why Veylqorix

Four guarantees

AI coding agents now write a large share of production code — fast, plausible, and occasionally unsafe. Lint and CI pipelines were not designed to verify that volume. Veylqorix fills the gap:

Guarantee 01

Real evidence, no fabrication

Every finding, severity, and exit code comes from an actual scanner run. A check that cannot run is reported SKIPPED or ERROR with a reason — never a clean pass.

Guarantee 02

One engine, many surfaces

CLI, MCP, GitHub Actions, and the dashboard are thin adapters over a single core, so security logic exists in exactly one place and behaves identically everywhere.

Guarantee 03

Deterministic gate

Exit codes are stable — 0 PASS, 1 FAIL, 2 INCOMPLETE — so CI branching is predictable and auditable run to run.

Guarantee 04

Agent-safe policy

An AI agent cannot suppress findings or raise thresholds: exceptions must be documented, capped, expirable, and visible in the committed policy file and every gate report.

One engine, many surfaces

Where Veylqorix plugs in

Every surface is a thin adapter over the same core engine (packages/core), so there is exactly one place where security logic lives:

CLI

01

Real scans, deterministic exit codes, safe dry-run hook installer. Not published to npm yet — run from dist/.

MCP server

02

Six validated tools, root-confinement + redaction. Requires pnpm build.

GitHub Actions gate

03

Real scan + SARIF upload, all actions pinned to SHAs. Advisory until a branch-protection rule requires the check.

Agent skills

04

Portable SKILL.md plus MCP configs for Claude Code, Codex, and Cursor.

Dashboard

05

Live scan data from the API; clearly-labeled DEMO MODE when the API is down.

Honest note

The gate and the CLI hooks are advisory until enforcement is in place — a branch-protection rule that requires the check, or a published CLI. Findings are produced and the check fails; a merge can still be forced. That is stated everywhere, never hidden.

Honest limitations

What Veylqorix is not

Read this first

  • Veylqorix reports what its scanners found. It does not certify the absence of vulnerabilities or secrets.
  • A scanner that cannot run makes the gate INCOMPLETE (exit 2) — degraded coverage is surfaced, never green-washed.
  • Regex secret detection has false positives and negatives; it complements tools like Gitleaks, it does not replace them.
  • License scanning is manifest-level, not a transitive license audit. A clean quality check is not a security certification.
