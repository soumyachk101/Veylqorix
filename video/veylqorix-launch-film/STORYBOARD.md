# Storyboard — Veylqorix Launch Film

A 50–60 second launch film. 16:9, 1920×1080 minimum, 30 fps, MP4/H.264, AAC audio.
Seven scenes. On-screen copy is verbatim — "Veylqorix" is never misspelled.
World: warm-ivory family with precise deep-navy structure (verified site
tokens in `DESIGN.md`); pixel-grid and digital-disintegration motifs
throughout. See `SCRIPT.md` for the narration timing table.

## Scene table

| # | Time | Scene | Visual | On-screen copy | Sound |
|---|------|-------|--------|----------------|-------|
| S1 | 0–5s | **The silence before ship** | Near-empty warm-ivory frame. Few precise navy pixels on a thin architectural grid; suspended code fragments drift almost imperceptibly. | `Every line of code carries a decision.` | Near-silence + subtle mechanical pulse. |
| S2 | 5–12s | **The complexity of code** | 3D landscape of code fragments and dependency graphs. Coral = risk, muted teal = verified. Transition out via an expanding pixel fragment. | `But not every change is safe to ship.` | Pulse builds; mechanical texture under the landscape. |
| S3 | 12–19s | **The Veylqorix reveal** | Dimensional engineered geometric hero structure; slow orbit. The real Veylqorix wordmark (pixel-inspired — do not redesign it). | `Meet Veylqorix.` then `No Unsafe Code Gets Through.` | Music resolves into the theme. |
| S4 | 19–31s | **Security verification in motion** | Pipeline stages in sequence: code change intake → project/dependency discovery → scanners run → findings normalized + sensitive evidence redacted → policy evaluation. Visually distinct modules for dependency audit, secret detection, static analysis, quality checks, and policy evaluation. BLOCK and PASS are shown as distinct outcomes. | `Inspect.` then `Verify.` then `Enforce.` — each with short pauses between words. | Rhythmic mechanical accent per stage; short pauses between the three words. |
| S5 | 31–40s | **Engineering, not just appearance** | Modules for the Rust engine, CLI, MCP server, and AI skills, plus GitHub Actions, connecting into one system. Pixel-grid transitions between modules. | `Independent verification. Before code ships.` | Theme continues; steady, engineered feel. |
| S6 | 40–49s | **The moment of confidence** | The pipeline completes. PASS in site mint; BLOCK in site coral (verified tokens in `DESIGN.md` — the brief's reference hexes `#DDF5EF` / `#F2A6A6` are superseded). No fabricated stats, no fake customer logos. | `Confidence, built into the workflow.` | Music resolves. |
| S7 | 49–60s | **Final brand signature** | Clean ivory. The logo settles via a restrained pixel reveal. Generous negative space. | `VEYLQORIX`, `No Unsafe Code Gets Through.`, optional `Verify before you ship.` Hold the final frame. | Music ends; single soft confirm tick on the logo settle, then silence. |

## Transition notes

- S1 → S2: quiet push into the 3D fragment landscape.
- S2 → S3: expanding pixel fragment becomes the hero structure.
- S3 → S4: camera pulls back into the pipeline world.
- S4 → S5: pixel-grid wipe between pipeline and system modules.
- S5 → S6: system modules converge; gate outcome lands.
- S6 → S7: dissolve to clean ivory end card; final frame holds.
